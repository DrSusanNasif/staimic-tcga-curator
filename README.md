# STaiMIC TCGA Curator

An AI-ready multiomics data curation and audit framework for TCGA datasets.

## Goals

- Metadata harmonization
- Sample hierarchy auditing
- AI-readiness assessment
- Confounding detection
- Reproducible multiomics workflows

## Initial Target Cohorts

- TCGA-COAD
- TCGA-READ

## Technology Stack

- Python
- pandas
- Nextflow
- Conda
- Docker
